# Data Cleaning

### This is a major part of Machine learning that ultimately decides how accurate your model will be.

### Data cleaning is the process of finding and dealing with problems in a dataset so that the data becomes more reliable and useful for analysis.

## Various problems in data cleaning

### A dataset may contain

- Missing values
- Inconsistencies in texts and numbers
- Duplicate recors
- Incorrect data types
- Incorrect values
- Outliers
