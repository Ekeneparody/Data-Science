# **Data Science**

### **Data Science** is a field in computer science that uses computer programming, statistics, mathematics to clean, visualize, extract and predict information from raw data.

### Data science is about finding patterns in data through analysis and make future predictions that can solve problems.

### By using Data science companies can make:

- Better decisions
- Predictive analysis (What can happen in the nearest future)
- Pattern discoveries i.e whether good or bad patterns

### The Data science process includes:

- _Capturing_: Collecting raw data
- _Preparing_: Cleaning and transforming the data
- _Analyzing_: Visualizing the data for better insight and communication
- _Modelling_: Building machine learning algorithms to make predictions
- _Communicate_: Share insights using data visualization for communication to make better decisions

# Difference between Data analytics and Data Science

### Data analytics studies data to share insight to guide decisions while Data science creates algorithms that predict future outcome

### Data analytics asks the questions what happened and why did it happen?

### Data Science asks what is going to happen and how it can be automated
